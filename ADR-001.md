# ADR-001: Base de Datos Elegida
**Estado:** Aceptado

## Contexto
El sistema requiere almacenar la información de los contactos que interactúan con el bot de Telegram y guardar su historial de chat.

## Alternativas consideradas
* MongoDB (NoSQL)
* PostgreSQL (Relacional)

## Decisión
Se eligió **PostgreSQL** por el soporte nativo optimizado de Entity Framework Core mediante el proveedor `Npgsql` y debido a que el modelo conversacional encaja perfectamente en una estructura relacional clásica de uno a muchos con transacciones ACID duraderas.

## Consecuencias
* **Ganancia:** Integridad referencial estricta y velocidad de consulta optimizada mediante Fluent API.
* **Resignación:** Rigidez de esquemas si se desearan añadir campos dinámicos heterogéneos en el futuro.
